# Mobile — FamilyRoots

Flutter mobile app for Android, iOS, and Tablet.

## Architecture

Clean Architecture with BLoC state management:

```
lib/
├── main.dart              # Entry point
├── app/                   # App config (router, theme, MaterialApp)
├── core/                  # DI, networking, error handling, constants
├── features/              # Feature-first modules
│   ├── auth/              # Authentication
│   ├── family_tree/       # Family tree viewer
│   ├── members/           # Member profiles
│   ├── documents/         # Photo/document management
│   ├── events/            # Anniversaries and events
│   └── notifications/     # Push notifications
└── shared/                # Shared widgets, extensions, l10n
```

Each feature follows Clean Architecture layers:
- `data/` — API calls (Dio), local cache (Hive)
- `domain/` — Entities, Repository interfaces, Use Cases
- `presentation/` — BLoC, Pages, Widgets

## Setup

**Prerequisites**: Flutter SDK (stable channel), Android Studio / Xcode

```bash
# Generate platform dirs (first time only)
flutter create --platforms=android,ios .

# Get dependencies
flutter pub get

# Run code generation
dart run build_runner build --delete-conflicting-outputs

# Copy environment file
cp .env.example .env

# Run the app
flutter run
```

## Commands

```bash
flutter pub get          # Get dependencies
flutter analyze          # Lint
flutter test             # Run tests
flutter run              # Run on connected device
flutter build apk        # Build Android APK
flutter build ios        # Build iOS (requires macOS + Xcode)
```

## Platform Directories

The `android/` and `ios/` directories are generated by `flutter create`.
If they don't exist, run:

```bash
flutter create --platforms=android,ios .
```

This will generate platform-specific boilerplate. Customize the bundle ID,
app name, and signing configuration afterward.
